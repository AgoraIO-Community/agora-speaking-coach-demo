# Agora Multilingual Speaking Coach Demo

## 1. Overview

Practice Spanish, French or German with English instructions, explanations and feedback. Ask explicitly for immersion in the selected language. Feedback is based on recognized text, not acoustic analysis. Do not score or assess pronunciation, accent, fluency or certified proficiency, and do not infer a CEFR level. Do not invent learner utterances or treat lesson examples as actual history. Ask for repetition when recognition is unclear. Role-play is fictional and does not place orders, schedule meetings or save progress. Keep exercise details only in this conversation; do not infer real personal attributes from fictional practice. English guidance is the default unless immersion in the selected language is explicitly requested; a request for harder practice is not consent to immersion. Do not request legal names, addresses, payment details or secrets.

## 2. Try the Demo

Use [local setup](https://github.com/AgoraIO-Community/agora-speaking-coach-demo/blob/main/README.md#run-it). Select a practice language and choose `Start practice`, allow microphone access and try: “I am a beginner. Help me introduce myself in Spanish.” Ask for a verbal recap before ending. Each session ends after ten minutes. No real outbound phone call is placed.

## 3. Architecture & Tech Stack

Next.js, React, TypeScript, Agora Conversational AI, Agents SDK, RTC and RTM. The existing browser voice lifecycle is unchanged. Next.js signs tokens and starts/stops the managed Agent; no business database or external action is connected.

## 4. Prerequisites & Configuration

Use Node.js 24, pnpm 9.15.9 and an Agora project with Conversational AI enabled. Create `.env.local` from `env.local.example` only when absent. Set public `NEXT_PUBLIC_AGORA_APP_ID` at build/runtime and server-only `NEXT_AGORA_APP_CERTIFICATE`. Never expose the certificate in browser code. The default managed models need no separate vendor key.

## 5. Quick Start

```bash
pnpm install --frozen-lockfile
pnpm run doctor
pnpm run dev
```

Open http://localhost:3000. Preserve existing credentials. The npm creator remains `npx agora-speaking-coach-demo@latest my-app`; a published version can differ from this local source.

## 6. How It Works

The start action fetches a combined RTC/RTM token and invites the Agent using requester_id and channel_name. Instructions are generated by `lib/agent-config.ts`. Tools remain disabled. Corrected details and simulation outcomes exist only in the current conversation; there is no saved result or cross-session memory.

## 7. Customize for Your Business

Edit `lib/agent-config.ts` for the role, workflow and guardrails, `lib/lessons.ts` for teaching examples, `lib/presentation.ts` for public identity, and `components/ScenarioFaq.tsx` for usage answers. `lib/runtime-profile.ts` owns model and voice defaults. Existing repository, npm package and Recipe identifiers remain stable.

## 8. Deployment & Validation

Follow [deployment instructions](https://github.com/AgoraIO-Community/agora-speaking-coach-demo/blob/main/README.md#deployment). Run `pnpm run verify`; Docker checks use `pnpm run verify:docker` separately. Inspect desktop/mobile pages, FAQ and Phrasebook, and inline startup failure/retry. Synthetic tests and builds do not establish real model behavior, bilingual speech quality, hosted connectivity or actual business operations. Real speech acceptance is separate. No publication or deployment is performed by this source update.
