# Agora Multilingual Speaking Coach Demo

## 1. Overview

Practice Spanish, French, German, Portuguese, Japanese or Korean with English instructions, explanations and feedback. Choose a lesson from a beginner curriculum of can-do objectives; the coach teaches the selected lesson. Ask explicitly for immersion in the selected language. Feedback is based on recognized text, not acoustic analysis. Do not score or assess pronunciation, accent, fluency or certified proficiency, and do not infer a CEFR level. Do not invent learner utterances or treat lesson examples as actual history. Ask for repetition when recognition is unclear. Role-play is fictional and does not place orders, take payments or schedule meetings. Saved progress is practice history only (lessons, dates, turn counts and recorded corrections); it is never a score or a proficiency level. Do not infer real personal attributes from fictional practice. English guidance is the default unless immersion in the selected language is explicitly requested; a request for harder practice is not consent to immersion. Do not request legal names, addresses, payment details or secrets.

## 2. Try the Demo

Use [local setup](https://github.com/AgoraIO-Community/agora-speaking-coach-demo/blob/main/README.md#run-it). Select a practice language and a lesson, choose `Start practice`, allow microphone access and try: “Yes, I’m ready. Please go slowly.” Ask for a verbal recap before ending; the ended screen then shows an unsaved practice summary. Each session ends after ten minutes. No real outbound phone call is placed.

## 3. Architecture & Tech Stack

Next.js, React, TypeScript, Agora Conversational AI, Agents SDK, RTC and RTM. The existing browser voice lifecycle is unchanged. Next.js signs tokens and starts/stops the managed Agent; practice history is saved through a pluggable store (file, SQLite or Postgres); no business database or external action is connected.

## 4. Prerequisites & Configuration

Use Node.js 24, pnpm 9.15.9 and an Agora project with Conversational AI enabled. Create `.env.local` from `env.local.example` only when absent. Set public `NEXT_PUBLIC_AGORA_APP_ID` at build/runtime and server-only `NEXT_AGORA_APP_CERTIFICATE`. Never expose the certificate in browser code. The default managed models need no separate vendor key. Speech recognition runs on Agora ARES with English plus the practice language as candidate languages and the selected lesson's phrases as keywords; server-only `COACH_STT_VENDOR=deepgram` returns to Deepgram nova-3 `multi` and `COACH_STT_KEYWORDS=off` sends no keywords (see `env.local.example` for what was measured).

## 5. Quick Start

```bash
pnpm install --frozen-lockfile
pnpm run doctor
pnpm run dev
```

Open http://localhost:3000. Preserve existing credentials. The npm creator remains `npx agora-speaking-coach-demo@latest my-app`; a published version can differ from this local source.

## 6. How It Works

The start action fetches a combined RTC/RTM token and invites the Agent using requester_id and channel_name, plus the selected `practice_language` and `lesson_id` and, for a lesson flagged `takesLearnerName` in the curriculum, an optional `learner_name` (first name or nickname, sanitized on the server, used for that session's instructions and greeting only). Instructions are generated by `lib/agent-config.ts`. The instructions include a short history of the learner's saved practice. By default the coach has no tools: the page reports each finished session and the learner marks lessons complete. Setting `COACH_PUBLIC_BASE_URL` to a public address lets the coach record corrections and the lesson result itself, and with `AGORA_WEBHOOK_SECRET` the finished conversation's text is logged from Agora's webhook. Progress is practice history without accounts: an anonymous browser cookie plus a learner code for switching devices. It is never a score.

## 7. Customize for Your Business

Edit `lib/agent-config.ts` for the role, workflow and guardrails, `lib/curriculum/` (registered in `lib/lessons.ts`) for the curriculum: the shared lesson skeleton and one pack per language, `lib/presentation.ts` for public identity, and `components/ScenarioFaq.tsx` for usage answers. `lib/runtime-profile.ts` owns model and voice defaults. Existing repository, npm package and Recipe identifiers remain stable.

## 8. Deployment & Validation

Follow [deployment instructions](https://github.com/AgoraIO-Community/agora-speaking-coach-demo/blob/main/README.md#deployment). Run `pnpm run verify`; Docker checks use `pnpm run verify:docker` separately. Inspect desktop/mobile pages, FAQ and Phrasebook, and inline startup failure/retry. Synthetic tests and builds do not establish real model behavior, bilingual speech quality, hosted connectivity or actual business operations. Real speech acceptance is separate. No publication or deployment is performed by this source update.
